Client: a small clinic chain wants a web dashboard and report layout patients to view
vendor lab results. Requirements for web dashboard: 
- Each vendor lab results may come with multiple test results. For each vendor lab result, show 1-2 most relevant test result, which is the one that patient can take action to improve their health.
- Show each test result with its value and unit
- Show the normal reference range for each test
Audience: doctor and nurses

Requirement: 
- Add patient follow-up, if given
- Group tests into panels (e.g. biological age,  cholesterol, kidney, liver)
Audience: patients, non-technical. Keep it simple and reassuring.
